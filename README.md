# Chispamental

Juego web de agilidad mental: matemática rápida, memoria, lógica y trivia escolar (lenguaje, ciencias, geografía, historia), con 3 niveles de dificultad.

## Jugar

Abre `index.html` en un navegador, o publícalo con GitHub Pages (Settings → Pages → Deploy from branch → `main` → `/root`).

## Estructura

- `index.html` — pantallas (menú, juego, resultado)
- `assets/style.css` — estilos y animaciones
- `assets/app.js` — lógica de los 4 modos de juego
- `assets/questions.js` — banco de preguntas de trivia escolar

No requiere build ni dependencias: es HTML/CSS/JS puro.
